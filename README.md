
# 🥚 Smart Egg Production System

![Python](https://img.shields.io/badge/Python-3.14-blue)
![Version](https://img.shields.io/badge/Version-1.0-success)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)
![License](https://img.shields.io/badge/License-MIT-orange)

A Python-based poultry farm management system for recording egg production, analyzing farm performance, managing users, and generating professional reports.


---

## Features

### 🔐 Login System
- Secure login
- Three login attempts
- Multiple users
- User roles

### 👥 User Roles

**Administrator**
- Add users
- View users
- Change passwords
- Delete users

**Manager**
- View users
- Change password

**Employee**
- Login
- Use the farm system

---

## Farm Features

- Add Record
- View Records
- Search Records
- Edit Records
- Delete Records

---

## Reports

- Production Summary
- Farm Dashboard
- Business Analytics
- Production Forecast
- Feed Efficiency Analysis

---

## Export

- Excel Report
- PDF Report
